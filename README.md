## Tarea 1 Inteligencia Artificial

El main de este proyecto corre 5 agentes de busqueda sobre los mapas de 1 a 3 mencionados en utils/mapas.py, mapa 4 es de testing y no se usa

# Requisitos
- Python 3.10 o superior
- numpy

# Instrucciones de ejecución
El proyecto funciona desde la raiz, para correr ejecute:

python main.py <num_agentes> <num_iteraciones>
